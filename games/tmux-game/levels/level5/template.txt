Level 5 - Switch windows

        This shell exports a helper function named `tmuxa`.
        Always use `tmuxa ...` so you stay inside the game's isolated tmux server.

        Session `nav` has windows `main` and `logs`. Make `logs` the active window.
You can attach and use Ctrl-b n/p, or use `tmuxa select-window -t nav:logs`.

        Type `exit` when you are done.
