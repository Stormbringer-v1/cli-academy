BOSS 01 - Sessions and Windows

        This shell exports a helper function named `tmuxa`.
        Always use `tmuxa ...` so you stay inside the game's isolated tmux server.

        Create two sessions named `prod` and `staging`.
Each session must have three windows named `shell`, `editor`, and `logs`.
Then kill the `prod` session and leave `staging` running.

        Type `exit` when you are done.
