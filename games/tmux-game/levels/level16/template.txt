Level 16 - Move panes between windows

        This shell exports a helper function named `tmuxa`.
        Always use `tmuxa ...` so you stay inside the game's isolated tmux server.

        Session `movepane` has window `one` with 3 panes and window `two` with 1 pane.
Move one pane so both windows end with 2 panes each.

        Type `exit` when you are done.
