== Level 10: Local Port Forwarding ==

Forward a local port to access remote services through SSH tunnel.

Task:
  1. The remote server has a web service on port 80
  2. Set up local port forwarding:
     ssh -L 8080:localhost:80 -p 2230 player@127.0.0.1
  3. In ANOTHER terminal, curl localhost:8080
  4. The page should load through the tunnel
  5. Write the curl output to answer.txt
  6. Exit the SSH session (the tunnel will close)
