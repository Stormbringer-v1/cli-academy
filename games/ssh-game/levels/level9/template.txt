== Level 9: SFTP Interactive Transfer ==

SFTP provides an interactive file transfer session.

Task:

  2. Password: cliacademy
  3. At the sftp prompt, try:
     - pwd (print working directory)
     - ls (list files)

  4. Exit with: bye
