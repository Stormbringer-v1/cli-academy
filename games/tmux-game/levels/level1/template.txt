Level 1 - Name a session

        This shell exports a helper function named `tmuxa`.
        Always use `tmuxa ...` so you stay inside the game's isolated tmux server.

        A session named `temp` already exists. Rename it to `mysession`.
You can attach and use Ctrl-b $, or use `tmuxa rename-session -t temp mysession`.

        Type `exit` when you are done.
