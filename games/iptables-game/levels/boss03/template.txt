== Boss 03: nftables Firewall ==

Recreate your Boss 02 NAT/router setup using pure nftables!

Tasks:
  1. Enable IP forwarding: sysctl -w net.ipv4.ip_forward=1
  2. Create a nat table with POSTROUTING (MASQUERADE) and PREROUTING (DNAT)
  3. Create a filter table with input chain
  4. Add counter rules for SSH (22), HTTP (80), HTTPS (443)
  5. Write all nft commands to answer.txt
