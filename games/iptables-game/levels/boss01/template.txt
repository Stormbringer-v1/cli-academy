== Boss 01: Basic Firewall ==

Build a complete basic firewall from scratch!

Tasks:
  1. Set default INPUT to DROP
  2. Allow loopback interface (localhost): iptables -A INPUT -i lo -j ACCEPT
  3. Allow ESTABLISHED,RELATED connections
  4. Allow incoming SSH (port 22), HTTP (port 80), HTTPS (port 443)
  5. Write all your commands to answer.txt
