== Level 2: SSH Key Generation ==

Passwords are insecure. SSH keys are better.

Task:
  1. Generate an SSH key pair with: ssh-keygen -t ed25519
  2. When asked for file location, press Enter to accept default
  3. When asked for passphrase, press Enter (empty)
  4. Confirm with empty passphrase
  5. List your keys with: ls -la ~/.ssh/
  6. Write the key type (ed25519) to answer.txt
